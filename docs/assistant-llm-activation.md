# تشغيل نموذج الذكاء الاصطناعي المجاني للمساعد — دليل التفعيل

> الحالة: **كل الكود موجود وموصول بالفعل** — تطبيقًا وخادمًا. ما تبقى خطوة تشغيل
> واحدة (نشر الدالة + مفتاح مزوّد مجاني واحد) تُنفَّذ مرة واحدة من جهازك.

---

## 1. البنية الموجودة (لا حاجة لبناء أي شيء)

```
التطبيق (Flutter)
  └─ SupabaseLlmClient ──► Edge Function: ai-assistant
                              ├─ حد استخدام لكل زائر (rate limit)      ← 232/097
                              ├─ إجابات متعلَّمة: نفس السؤال = رد فوري  ← 097_ai_learned_answers
                              ├─ جُمل تدريب تُحقن في النموذج           ← 232_ai_conversation_training
                              ├─ فجوات معرفة تُسجل للتدريب لاحقًا        ← ai.assistant_knowledge_gaps
                              ├─ إعدادات ومفتاح المزوّد من لوحة الإدارة  ← 238/239 (Vault مشفّر)
                              └─ وكيل إلى مزوّد مجاني (المفتاح على الخادم فقط)
                                   1) GROQ_API_KEY      (مجاني، سريع جدًا)
                                   2) GEMINI_API_KEY    (مجاني، الأفضل بالعربي)
                                   3) OPENROUTER_API_KEY (مجاني)
```

- المفتاح **لا يخرج من الخادم أبدًا** — التطبيق يكلّم دالتك أنت فقط.
- الضيوف مدعومون، ولكل زائر حد استخدام، وإن فشل مزوّد يُجرّب التالي تلقائيًا.
- بدون أي مفتاح: المحرك المحلي (القواعدي المدرب على لهجتين) يجيب، فلا تتجمد الميزة أبدًا.

## 2. التفعيل — أمران فقط

```bash
# 1) نشر الدالة (من جذر المشروع)
supabase functions deploy ai-assistant --no-verify-jwt

# 2) مفتاح مزوّد مجاني واحد (اختر واحدًا):
supabase secrets set GEMINI_API_KEY=مفتاحك        # جوجل AI Studio — مجاني
# أو
supabase secrets set GROQ_API_KEY=مفتاحك GROQ_MODEL=llama-3.3-70b-versatile
# أو
supabase secrets set OPENROUTER_API_KEY=مفتاحك OPENROUTER_MODEL=meta-llama/llama-3.3-70b-instruct:free
```

**توصيتي:** ابدأ بـ **Gemini** (الأقوى فهمًا للعربية واللهجات ضمن المجاني)، واترك
`GROQ_API_KEY` احتياطًا — الدالة تُجرّب المزوّدين بالترتيب تلقائيًا.

> بديل بدون سطر أوامر: لوحة الإدارة تملك شاشة إعدادات المساعد
> (المزوّد + الموديل + المفتاح + النبرة) وتُخزَّن مشفّرة في Vault —
> جدول `ai.assistant_admin_config` (الترحيل 238) وRPC `admin_ai_assistant_save_config`.

## 3. التدريب على بيانات التطبيق — كيف يعمل فعليًا

النموذج **لا يُدرَّب بوزنٍ** (فيسبوك لا يسمح، ولا يفيد نموذجًا مجانيًا)، وإنما
بالطرق الثلاث التي تعطي النتيجة نفسها عمليًا:

1. **الإجابات المتعلَّمة (097):** كل سؤال أجابه النموذج جيدًا يُحفَظ ببصمة السؤال،
   فالسؤال نفسه من أي عميل يُجاب فورًا **بدون نداء النموذج** — أرخص وأسرع.
2. **جُمل التدريب (232):** جدول `ai.conversation_patterns` يُحقن في system prompt
   كأمثلة few-shot بأنماط الردود المتوقعة (تحية، منتج، طلب، ولاء، شكوى…) مع
   نبرة وتنويعات. أضِف أسطرًا جديدة فيه كلما ظهر أسلوب جديد يعجبك.
3. **فجوات المعرفة (232):** كل سؤال لم يجد له جوابًا في قاعدة المعرفة يُسجَّل في
   `ai.assistant_knowledge_gaps` (بعد موافقة العميل على الذاكرة) مرتبًا بحسب
   التكرار — راجعه واكتب له جوابًا فيتعلّم منه الجميع:

```sql
-- أكثر الأسئلة التي لم يعرف المساعد جوابها
select question_text, occurrences, last_seen_at
from ai.assistant_knowledge_gaps
where status = 'open'
order by occurrences desc, last_seen_at desc
limit 20;
```

كما أن التطبيق نفسه يواصل التعلم محليًا: كل محادثة تُستخرج منها تفضيلات العميل
ومنععه وروتينه وتصحيحاته، وكل عبارة نجح فهمها تُحفظ كدرس يُعاد استخدامه.

## 4. حماية الحصة المجانية

- حد لكل زائر في نافذة زمنية (`increment_assistant_rate_limit`) — لا يفشل مفتوحًا.
- سقف طول المحادثة (20 رسالة / 12 ألف حرف) ومهلة 15 ثانية.
- الإجابات المتعلَّمة تُنقص النداءات تلقائيًا مع الوقت.
- المحرك المحلي هو دائمًا الجواب الأول الذي يظهر للعميل؛ النموذج يزيد ويلمّع —
  فحصة المزوّد تُصرف على الأسئلة التي تستحق فعلًا.

## 5. التحقق بعد التفعيل

1. افتح المساعد واسأل سؤالًا خارج محرك القواعد مثل: «ليش أطلب منكم مش عن الكافيهات؟»
2. راقب سجل الدالة: `supabase functions logs ai-assistant`
3. أعد السؤال نفسه: يجب أن يُحفَظ فيذا يعود لاحقًا من `recall_learned_answer`
   بدون نداء المزوّد (يظهر في سجل الدياجنوستيك
   `event: "assistant_memory_learned"` ثم يصبح إجابة متعلّمة، وأيضًا
   `event: "assistant_knowledge_gap_recorded"` للأسئلة الجديدة).

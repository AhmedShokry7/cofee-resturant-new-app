# Preview package — تحديث المعاينة (قراءة كتالوج حقيقي)

البناء: `flutter build web --release -t lib/main_preview.dart --base-href=/cofee-resturant-new-app/preview/`

التغيير عن الحزمة السابقة (4377cbd):
- وضع المعاينة يتصل الآن بـ Supabase للقراءة فقط: المحاكي يعرض المنتجات
  والتصنيفات والبانرات الحقيقية كما يراها الزبون (إصلاح: الرئيسية لا تعرض
  كل شيء، التصنيفات فارغة، صفحات تظهر أخطاء تحميل).
- كل مسارات الكتابة تظل مغلقة (سلة في الذاكرة، تسجيل الدخول معطّل، الطلبات
  غير متاحة)، والجلسة لا تُستعاد — المعاينة زبون مجهول دائمًا.
